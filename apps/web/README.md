# apps/web

Versão web/PWA do Toda Voz: comunicador offline no navegador, para computadores, tablets e celulares onde não for possível instalar o app. É também a alternativa à verificação de desenvolvedor do Android.

- **Status:** a criar.
- **Módulos:** [02](../../context/modulos/02-comunicador-pranchas.md), [04](../../context/modulos/04-voz-saida.md), [10](../../context/modulos/10-papel-e-impressao.md).
- **Tecnologias:** PWA, com o núcleo compilado para WebAssembly (decisão pendente, [0009](../../context/decisoes/0009-nucleo-rust-interfaces-finas.md)).
