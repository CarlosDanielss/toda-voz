# hardware

Kits abertos e baratos: suportes de celular imprimíveis em 3D, botões acionadores, sensor EOG (ESP32 + AD8232), câmera infravermelha e imagem para Raspberry Pi.

- **Status:** a criar.
- **Módulo:** [15: Hardware e kits](../context/modulos/15-hardware-kits.md).
- **Parceiros naturais:** comunidades de makers que já mantêm projetos abertos de acessibilidade.
- **Licença:** projetos de hardware sob a licença de conteúdo do projeto. A licença específica de hardware (ex.: CERN-OHL) ainda não foi decidida.
