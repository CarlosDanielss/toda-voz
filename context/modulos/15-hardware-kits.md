# Módulo 15: Hardware e kits

## Para que serve
Mostrar que dá para ter um comunicador completo por uma fração dos US$ 5–20 mil do mercado, com **peças comuns e projetos abertos** em `hardware/`.

## Kits
| Kit | O que é | Custo aproximado |
|---|---|---|
| **0: Papel** | Prancha impressa + quadro de olhar ([módulo 10](10-papel-e-impressao.md)) | ~R$ 0–10 |
| **1: Celular da família** | O app em qualquer Android | R$ 0 |
| **2: Comunicador** | Android usado de 3–4 GB + suporte + botão faça-você-mesmo + alto-falante | ~US$ 60–120 [estimativa] |
| **3: Olhar e sensor** | Kit 2 + câmera infravermelha USB ou EOG | +US$ 15–30 [estimativa] |
| **4: Raspberry Pi** | Pi 5 + tela + caixa aberta | ~US$ 120–180 [estimativa] |
| **Estúdio de voz** | PC com placa de vídeo que atende uma comunidade | compartilhado |

## Funcionalidades
### Fase 1
- [ ] **Suporte de celular** imprimível em 3D (cadeira de rodas, cama, mesa).
- [ ] **Botão acionador** faça-você-mesmo (~US$ 8), aproveitando projetos abertos de makers.
- [ ] Lista de **celulares usados testados** (desempenho medido).

### Fase 2–3
- [ ] **Sensor EOG** com ESP32 + AD8232 [E28].
- [ ] **Câmera infravermelha** USB + LEDs de 850 nm, respeitando os limites de segurança IEC 62471.
- [ ] Imagem pronta para **Raspberry Pi**.
- [ ] EEG aberto como opção avançada [B7, B8].
