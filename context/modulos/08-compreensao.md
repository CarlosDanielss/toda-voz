# Módulo 08: Compreensão (modo "entender")

## Para que serve
Quase toda tecnologia de CAA ajuda a pessoa a **falar**. Este módulo ajuda a pessoa a **entender**: a mensagem recebida vira pictogramas, texto simples ou Libras.

## Para quem
Pessoas com afasia receptiva, deficiência intelectual, demência ou autismo, e pessoas surdas com pouco letramento em português.

## Funcionalidades
### Fase 3
- [ ] **Fala → texto** offline (whisper.cpp), com legenda grande.
- [ ] **Texto → pictogramas** a partir do grafo de conceitos (regras simples primeiro, depois ML).
- [ ] **Texto → leitura fácil** com um modelo de linguagem pequeno, **sempre revisável por uma pessoa**.
- [ ] **Texto → vídeos de Libras** do dicionário, para palavras e frases conhecidas.
- [ ] **Ferramentas do parceiro**: perguntas de sim/não, escolhas com figuras, escala de dor.

### Futuro
- [ ] Documentos em formato fácil (receitas médicas, avisos), com pictogramas.

## Riscos e perguntas abertas
- A simplificação automática pode distorcer o sentido: exige revisão humana e aviso.
- Há pouca avaliação específica com pessoas com afasia [lacuna].
